# 99 Archive

This directory permanently stores superseded, deprecated, or completed historical artifacts that are no longer actively maintained.

---

## 1. Directory Structure

```text
99_Archive/
├── README.md                  # Archive index and preservation log (this file)
├── Superseded_Governance/     # Retired workspace rules or deprecated standards
├── Superseded_Templates/      # Legacy deliverable templates
└── Retired_Projects/          # Completed, cancelled, or archived initiatives
```

---

## 2. Archival Policy
* Never delete historical records that provide context for why current decisions were made.
* Ensure all files moved here carry a header explicitly stating their decommission date, reason for retirement, and successor artifact link.
