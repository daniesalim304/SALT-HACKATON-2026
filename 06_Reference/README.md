# 06 Reference

This directory catalogs authoritative external references, RFCs, official framework documentation links, and industry standards used to validate solutions across the workspace.

---

## 1. Directory Structure

```text
06_Reference/
├── README.md                  # Index of external references and links (this file)
├── Official_Documentation/    # Links and summaries for approved languages, frameworks, DBs
├── Standards/                 # Industry standards, RFCs (HTTP, WebSocket, OAuth2, SemVer)
└── External_Resources/        # Whitepapers, academic research, and external architecture blogs
```

---

## 2. Reference Policy
* Do not duplicate full third-party manuals or large binary documentation sets. Store links, citations, version numbers, and concise summaries.
* Maintain citation metadata: Title, Source Organization, URL, Date Accessed.
