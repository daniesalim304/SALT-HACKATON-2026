# 05 Methodologies

This directory documents standard operating procedures (SOPs), analytical workflows, and execution methodologies for System Analysts and Solution Architects operating in this workspace.

---

## 1. Directory Contents

| Workflow Document | Scope & Focus |
|---|---|
| [project-intake-workflow.md](project-intake-workflow.md) | Protocol for onboarding a new initiative, scaffolding folders, and establishing initial project charter. |
| [pdf-analysis-workflow.md](pdf-analysis-workflow.md) | Step-by-step methodology for Phase 1–5 extraction, gap analysis, and clarification generation from source documents. |
| [requirements-engineering.md](requirements-engineering.md) | Standards for capturing, classifying (FR/NFR/BR), and tracing requirements to business goals. |
| [solution-architecture-workflow.md](solution-architecture-workflow.md) | Incremental design workflow (Trade-off analysis, C4/Mermaid modeling, technology justification). |
| [documentation-lifecycle.md](documentation-lifecycle.md) | Authoring, review, sign-off, and version evolution processes. |
| [knowledge-maintenance.md](knowledge-maintenance.md) | Hygiene rules, deduplication, broken link verification, and promotion into `03_Knowledge_Base/`. |

---

## 2. Methodology Principle

Methodologies describe **how** we do the work consistently and repeatably. They do not contain project-specific facts, which belong in `02_Projects/`.
